
# Recursos Informáticos

## Objetivo
Este proyecto reúne recursos gratuitos para aprender informática,
desarrollo web y gestión de proyectos.

## Recursos recomendados
- [MDN Web Docs](https://developer.mozilla.org/es/)
- [W3Schools](https://www.w3schools.com/)
- [GitHub](https://github.com/)

## Estructura del proyecto
- `index.html`: contiene la estructura de la página web.
- `style.css`: define los estilos visuales.
- `README.md`: documenta el proyecto.

## Cómo utilizarlo
Abre `index.html` en un navegador para consultar los recursos.

## Tecnologías utilizadas
- HTML5
- CSS3
- GitHub
